Aprendizagem baseada em prática

O usuário precisa navegar pelas páginas, realizar ações reais e alcançar pelo menos 6 de 7 acertos no teste. Assim, a conclusão não depende apenas de clicar em “próximo” no tutorial.

Onde o progresso fica salvo?

Ele é armazenado neste navegador. Em outro computador, navegador, perfil ou janela anônima, a trilha começa novamente porque o progresso não é sincronizado.

1DashboardEntender a situação geral da operação
  1. Observe os quatro indicadores: faturamento, pedidos, ticket médio e alertas de estoque.
  2. Use o gráfico de faturamento para comparar o desempenho entre os dias.
  3. Consulte o gráfico de status para identificar pedidos que precisam de atenção.
  4. Veja os pedidos recentes e acesse “Ver todos” quando precisar trabalhar na lista completa.

O usuário aprendeu quando: consegue explicar qual indicador ou gráfico deve consultar para cada decisão.

2ProdutosCadastrar e controlar catálogo e estoque
  1. Pesquise um produto pelo nome ou pelo SKU.
  2. Use o filtro para separar itens ativos, com estoque baixo ou sem estoque.
  3. Para cadastrar, clique em “Novo produto” e informe todos os campos obrigatórios.
  4. O SKU deve ser único. O sistema impede o cadastro de códigos repetidos.
  5. Use “Editar” para corrigir nome, categoria, preço, SKU ou quantidade.
  6. Use “+10 estoque” para simular uma reposição e observe a atualização automática do status.
  7. Exclua um item somente quando tiver certeza, pois a ação remove o registro da demonstração.

Regra de estoque: 0 unidade = sem estoque; de 1 a 10 = estoque baixo; acima de 10 = ativo.

3PedidosLocalizar vendas e atualizar o fluxo
  1. Digite o número do pedido ou o nome do cliente na pesquisa.
  2. Combine a pesquisa com o filtro de status para reduzir a lista.
  3. Confira cliente, canal, data e valor antes de alterar qualquer informação.
  4. Atualize a etapa pelo seletor da última coluna.
  5. Interprete as cores: verde para pago/enviado, amarelo para pendente, vermelho para cancelado e azul/cinza para processando.

Boa prática: antes de cancelar ou avançar um pedido, confirme o número e o cliente para evitar alterações no registro errado.

4ClientesConsultar relacionamento e histórico
  1. Pesquise pelo nome ou e-mail.
  2. Verifique o segmento do cliente: Novo, Recorrente ou VIP.
  3. Compare quantidade de pedidos e total comprado para entender o relacionamento.
  4. Use os indicadores superiores para acompanhar clientes ativos, recompra, VIPs e novos clientes.

O usuário aprendeu quando: consegue localizar um cliente e explicar se ele é novo, recorrente ou de alto valor.

5Tutorial, trilha e reinícioRever ou começar o treinamento novamente
  1. Use “Rever tutorial desta página” para repetir apenas as explicações da página atual.
  2. Use “Reiniciar trilha” para apagar apenas o progresso de aprendizagem.
  3. Produtos, pedidos e tema são mantidos quando apenas a trilha é reiniciada.
  4. Use “Restaurar dados de demonstração” somente para voltar todo o projeto ao estado original.
6Acessibilidade com VLibrasTraduzir textos do sistema para Libras
  1. Localize o botão flutuante do VLibras na lateral direita da página.
  2. Clique no botão para abrir o tradutor e carregar o avatar.
  3. Selecione ou destaque um texto da página para solicitar sua tradução para Libras.
  4. Use os controles do próprio VLibras para reproduzir, pausar ou fechar o tradutor.
  5. O recurso precisa de conexão com a internet para carregar o serviço oficial.

Importante: o VLibras é um recurso complementar de acessibilidade e não substitui textos claros, boa organização visual e navegação por teclado.

Teste baseado em situações reais

São 7 perguntas. É necessário acertar pelo menos 6. Além do teste, a trilha exige que o usuário realize ações práticas no sistema.

1. Você precisa encontrar o pedido #1045 de Rafael Lima que está pendente. Qual é a forma mais segura?

2. Um produto possui 8 unidades. Qual status o sistema deve apresentar?

3. Ao cadastrar um novo produto, o sistema informa que o SKU já existe. O que fazer?

4. Um item está com 0 unidades e você usa “+10 estoque”. Qual será o resultado esperado?

5. Antes de alterar um pedido de Pendente para Pago, o que deve ser conferido?

6. Você quer identificar um cliente recorrente e avaliar sua importância. Onde olhar?

7. A trilha desapareceu porque foi concluída. Como refazer o treinamento sem apagar produtos e pedidos?
